# Fotky do celostránkových pásů

Sem nahrajte vlastní fotky (ideálně **vaše stroje v terénu / vaše pobočky**),
ať web vypadá autenticky. Zachovejte přesně tyto názvy:

- **onas.jpg**   → pás na stránce „O společnosti"
- **sluzby.jpg** → pás na stránce „Služby"

## Doporučení
- Na šířku (landscape), poměr ~16:9, šířka alespoň 1600 px
- Akční záběr (stroj při práci, areál pobočky) působí nejlíp
- Text v pásu je vlevo dole, takže nechte vlevo trochu „klidnějšího" místa

Dokud nenahrajete vlastní, zobrazují se náhradní fotky New Holland.
